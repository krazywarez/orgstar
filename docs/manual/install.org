#+TITLE: Install
#+DESCRIPTION: Installing orgstar on the Mac with Homebrew or a download, and on iPhone and iPad from the App Store.
#+LEDE: The Mac app comes as a notarized download and a Homebrew cask; the iOS app is on the App Store.

* Requirements

- macOS 26 or later.
- Optional: GNU Emacs, for the features that hand work to it on the Mac
  (Emacs Lisp code blocks that need full Emacs, Lisp table formulas the built-in
  interpreter can't run, and export to PDF, LaTeX, ODT and other formats). See
  [[file:guide/15-alongside-emacs.org][Working alongside Emacs and other tools]].

* The Mac app

** With Homebrew

#+BEGIN_SRC sh
brew tap krz/tap https://gitbay.org/krz/homebrew-tap.git
brew install --cask orgstar
#+END_SRC

** As a download

Download the newest =orgstar-<version>.dmg= from [[https://files.krz.sh/orgstar/][files.krz.sh/orgstar]], open it, and drag
orgstar to Applications. The app is universal (Apple silicon and Intel), signed with a
Developer ID and notarized by Apple, so it opens without warnings.

Once the app has been launched, Finder opens =.org= files with it, Quick Look shows
them formatted, and Spotlight indexes their headings and text.

* The iOS app

The iPhone and iPad app (iOS 26 or later) is on the [[https://apps.apple.com/us/app/orgstar-org-mode-agenda/id6821552018][App Store]]. The Apple Watch
app comes with it. The App Store keeps it up to date.

See [[file:guide/14-ios.org][iPhone and iPad]] for what it does.

* Updating

orgstar checks for a new release once a day, after asking on its second launch whether it
may; orgstar ▸ Check for Updates… checks now, and Settings ▸ General has the switch. An update
downloads, is checked against the key the releases are signed with, and installs when you
agree. With Homebrew, =brew upgrade --cask orgstar= works too; the cask leaves updating to the
app otherwise. From source, pull and build again (a build without a Developer ID never checks):

#+BEGIN_SRC sh
git pull
scripts/build-app.sh
#+END_SRC

Your settings live in =~/.config/orgstar/= and survive rebuilds.

* Uninstalling

Delete =orgstar.app=, or run =brew uninstall --cask orgstar=. To remove your settings as
well, delete =~/.config/orgstar/= (=brew uninstall --zap --cask orgstar= does both).
Your org files are never stored inside the app.
